# Privacy Policy — SpaceMedic Public Edition

SpaceMedic is offline-first and collects no telemetry.

## Data processed locally

To provide its features, SpaceMedic may read local file metadata, installed-app metadata, selected cache paths, Windows service/task information, and command output from Windows/vendor tools. This data stays on the computer unless the user explicitly exports a report.

SpaceMedic does not require an account, analytics identifier, API key, advertising SDK, or cloud service. It does not automatically upload files, reports, diagnostics, installed-app lists, project names, browser data, credentials, or Registry data.

## Diagnostic bundles

Diagnostic ZIP files are created only when the user presses the diagnostics button. Absolute paths are redacted and the bundle excludes file contents, source code, installed-app inventory, browser history, credentials, and Registry dumps. Users must review `diagnostics.json` before sharing it.

## Updates

Automatic network update checks are disabled by default in the public edition. Builds and releases may be downloaded manually from the project's official repository.

## Cleanup rules

Community rule files are local JSON files. SpaceMedic never downloads rules automatically. Users should audit third-party rules before copying them into the local rules file.
