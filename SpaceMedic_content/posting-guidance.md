# Posting Guidance

## What Makes This Project Interesting
The ability to safely and transparently analyze and reclaim unused disk space and memory on Windows systems

## What Should I Post?
A post highlighting the importance of disk space and memory management, introducing SpaceMedic as a free and open-source solution, and explaining its key features and technical approach, including the use of native Windows APIs and low-overhead process snapshot

## Target Audience
Windows users, developers, and support technicians interested in optimizing system performance and managing resources

## What to Avoid Claiming
Unsubstantiated claims about the application's performance, security, or ability to reclaim disk space, as well as any exaggerated statements about its features or capabilities
