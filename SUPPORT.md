# Support

Before requesting help:

1. Read `README.md` and `WINDOWS_TEST_CHECKLIST.md`.
2. Reproduce the issue with the latest release.
3. Note Windows version, SpaceMedic version, standard/Admin mode, action used, and exact error.
4. Create and review the privacy-redacted diagnostic bundle if relevant.

Do not share credentials, private source code, browser data, license keys, personal documents, or unreviewed diagnostics.

SpaceMedic cannot guarantee recovery of permanently deleted data. Keep backups and review every destructive action.
